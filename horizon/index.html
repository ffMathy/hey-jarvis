Jarvis

He appears in the room with you, in passthrough, on a Meta Quest. Say “Hey Jarvis” and he answers.

No key and no microphone needed: select him to see him speak, listen and think.

When the headset can keep his voice out of its own microphone, you hear him from his spot in the room. Otherwise, or with this off, you hear him from the headset.

Your ElevenLabs agent

Jarvis is an ElevenLabs agent. The API key is kept in this browser's local storage, which is not a keystore: anything running on this site can read it. Make a key for Jarvis alone.

  • Create an ElevenLabs account Free to start. The agent runs on their side, which is why this page needs to be told where to find it.
  • Build an agent Give it a voice and a personality, and connect it to your own services with tools.
  • Where the agent ID is Open your agent in the dashboard. The ID is the last part of the address, and it starts with agent_.
  • Create an API key Make one for this headset alone, so that losing it means revoking one key rather than all of them.

No headset? See him on a desktop.
